# 反趋势策略图表解读（`contrarian_reversal_strategy_result`）

本节对应 `contrarian_reversal_strategy_result/` 中的图表，基于最近一次回测（权益末值 10.88，累计收益 9.88，年化约 9.0%，夏普≈1.12，最大回撤 -27.5%，胜率 73.5%），用于快速解读策略表现与风险。

### 术语说明
- PnL：Profit and Loss，单笔或汇总的收益/损益；为正代表盈利，为负代表亏损。
- Equity：权益曲线，初始 1.0 经逐期乘以（1+PnL）累乘得到的组合价值。
- Gross Leverage：当期组合总绝对仓位（含多/空的绝对值），受 `gross_cap` 限制。

## `equity_curve.png`
- 含义：按退出日聚合 PnL 的组合权益曲线。
- 观察：整体向上，期间出现约 27% 的回撤后修复。长样本内收益主要来自若干阶段性行情（权益阶梯式上移）。
- 原因：信号集中在明显趋势后的反转段，季频权重高（见下），在大波动阶段贡献显著；组合总仓位上限 1.0 限制了杠杆，波动相对可控。

## `pnl_by_frequency.png`
- 含义：按频段汇总的 PnL。
- 结果：季频 +1.96，周频 +0.70，月频 +0.09 → 季频占主导。
- 原因：季频触发门槛较低（连涨/跌≥5、振幅≥10%），且持有 3 季度，能抓住大波段反转；月频阈值苛刻（8 连涨/跌、振幅 8%），信号稀疏且贡献有限。
- 目的：做“来源归因”（哪一类频段贡献了多少绝对收益），便于调参。它回答的是“如果只看这一类信号，贡献了多少累计 PnL”。
- 与总收益的关系：
  - 这里的频段 PnL 是“加总收益”，不是“复利后的终值”。最终权益 10.88 来自按退出日的连续复利：`Equity = ∏(1 + 当日组合Pnl)`，复利会放大长期回报。
  - 频段 PnL 之间也存在时间叠加（同日不同频段一起交易会触发组合缩放），因此单独加总的 1.96+0.70+0.09≈2.74 无法简单映射到累计收益 9.88。
  - 可以把频段 PnL 理解为“若按当前仓位和成本设定，把某频段的交易放入组合所产生的累积贡献”，用于判断哪些频段值得保留/放大，哪些阈值需要放松或收紧。

## `pnl_top_assets.png`
- 含义：资产贡献前 10。
- 结果：港股科技/地产与成长风格居前（如“恒生综合行业指数-资讯科技业”“恒生指数”“恒生地产分类指数”“中信风格指数:成长”），单品贡献 0.17–0.32 区间。
- 原因：港股及成长风格波动大，易出现连续单边 → 反转信号频率与振幅更高；EQUITY 类别的敏感度 4.0 和上限 40% 带来了较高权重。

## `pnl_bottom_assets.png`
- 含义：资产贡献后 10（部分为轻微正/负）。
- 结果：最差为 CBOT 大豆期货约 -0.006，其余（美债10年、煤炭、LME 铜、伦敦银等）小幅正/负，绝对值很小。
- 原因：商品和债券类的信号密度/振幅不高，且仓位上限较低（COMMO 35%，BOND 50%），对组合拖累有限。

## `trade_pnl_distribution.png`
- 含义：单笔交易 PnL 的分布。
- 结果：均值 0.018， 中位数 0.009，标准差 0.043，最小 -0.072，最大 0.244；盈利占比约 73.5%。
- 解读：分布右偏，少量大额盈利拉高均值；止损未显式设定，但仓位和成本控制使得单笔亏损幅度受限。

## `streak_lengths.png`
- 含义：触发信号的连续涨跌期数分布。
- 结果：集中在 6–8 期，均值约 7；上界到 12。
- 原因：各频段的门槛（周≥7，月≥8，季≥5）决定了信号起点，超过门槛后仍计入更长 streak，因此右侧有尾巴。

## `gross_leverage.png`
- 含义：按进场日统计的组合总绝对仓位（含缩放后权重）。
- 结果：多数时间在 0.4–1.0 之间，均值约 0.69，峰值受 `gross_cap=1.0` 限制。
- 原因：同日多标的触发时需按组合上限等比例缩放；季频与周频信号重叠时杠杆更高，信号稀疏期则较低。

## 可能的改进方向
- 放宽月频阈值或缩短持有期，提高月频贡献稳定性。
- 若需降低回撤，可调低单标/组合上限或开启做空对冲；若追求收益，可在控制风险的前提下适度提高 `gross_cap`。
- 针对港股/成长高波动性，可单独设定更平滑的仓位上限或分段止盈，减少单市场的集中度。
